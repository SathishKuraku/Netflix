# Netflix Clone 🎬

A modern, responsive **Netflix Clone** web application built using **HTML** and **CSS**. This project replicates the iconic user interface of Netflix, featuring a hero showcase banner, categorized movie shelves, trending sections, and a top 10 movies layout.

---

## ✨ Features

* **Responsive Navigation Bar:** Includes a Netflix logo, navigation links (Home, TV Shows, Movies, New & Popular, My List, Browse), live search input, notification bell, and user profile icon.
* **Hero Showcase Banner:** Highlights a featured series (*Stranger Things*) complete with ratings, release year, age rating, seasons, description, and interactive **Play** and **More Info** buttons.
* **Trending Now Section:** Displays a horizontal scrollable row of popular titles with hover-to-play indicators.
* **Popular on Netflix:** Showcases curated posters using dynamic image grids.
* **Top 10 Movies in India:** A numbered rank layout highlighting the top trending content.
* **FontAwesome Integration:** Uses FontAwesome icons for UI elements like search, play buttons, stars, and user profiles.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure.
* **CSS3:** Flexbox, grid, and modern styling.
* **FontAwesome:** Icon library for UI controls and media buttons.

🚀 Getting Started
To view or run this project locally, follow these simple steps:

1. **Clone the repository:**

```Bash
git clone [https://github.com/SathishKuraku/Netflix.git](https://github.com/SathishKuraku/Netflix.git)
```
2. **Navigate to the project directory:**

```Bash
cd Netflix
```
3. **Open the project:**

* Open index.html directly in your preferred web browser.

* Alternatively, use a live server extension (such as Live Server in VS Code) for an optimal local development experience.
